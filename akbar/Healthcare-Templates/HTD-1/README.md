# Celestial Smiles Dental Clinic — Next.js Application

A modern, high-performance web application converted from the mirrored Wix website for **Celestial Smiles Dental Clinic** (Dr. Fatema Khanbhai - Bandra West, Mumbai).

Built with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, and **Lucide Icons**.

---

## 🌟 Pages & Key Features

1. **Home (`/`)**:
   - Header with clinic hours, direct call hotline, location, and Instagram link.
   - Sticky navigation bar with mobile hamburger menu and appointment CTA.
   - Hero banner with award badge, lead doctor credentials, and floating 5.0 Google Rating & 1,000+ Happy Patients badges.
   - **Meet Dr. Fatema Khanbhai (B.D.S., F.A.D.)**: Gold Medalist & German Fellowship bio.
   - **A Look Around Celestial Smiles**: Interactive virtual clinic tour carousel.
   - **Comprehensive Dental Care**: 5 core treatments (Emergency Dental Care, Laser Teeth Whitening, Routine Check-ups, Dental Fillings, Traditional Braces/Orthodontics).
   - **Our Smile Transformations Preview**: Interactive Before/After toggle cards.
   - **Patient Reviews**: Real Google reviews (Neeta Chandhok, Zain Fezi, Aamir Potia).
   - Floating WhatsApp button for instant consultations.

2. **Contact & Appointment Booking (`/contact-us`)**:
   - Interactive appointment booking form with name, email, phone, date picker, treatment selector, and **teeth image upload preview**.
   - Direct call and WhatsApp instant confirmation options.
   - Embedded Google Maps with interactive directions to the Bandra West clinic.
   - Clinic hours and emergency notices.

3. **Smile Gallery (`/smile-gallery`)**:
   - Filterable categories: *All, Cosmetic, Whitening, Restoration, Orthodontics*.
   - **Interactive Before/After comparison sliders** allowing patients to drag between the before and after states.
   - High-resolution treatment cases.

4. **School Dental Camps (`/school-dental-camps`)**:
   - Community outreach overview and pediatric oral hygiene education.
   - Photo gallery of past dental camps in Mumbai schools.
   - School collaboration inquiry banner.

5. **SEO & Technical Feats**:
   - Dynamic `/sitemap.xml` and `/robots.txt`.
   - OpenGraph and Twitter card social meta tags.
   - Structured JSON-LD schema (`Dentist` / `LocalBusiness`).
   - 100% static prerendering with lightning-fast load times.

---

## 🚀 How to Run Locally

```bash
# Navigate to the project directory
cd celestial-smiles-nextjs

# Run the development server
npm run dev

# Or build for production
npm run build
npm run start
```

Visit [http://localhost:3000](http://localhost:3000) (or custom port).
