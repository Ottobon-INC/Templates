# 🎓 Education Templates Hub & Directory

A unified portal to access, review, and test all School and College website templates created in this workspace.

---

## 🚀 Quick Access

### Method 1: Direct File Opening
Double-click [`index.html`](./index.html) in this folder or open it in any web browser (`file:///.../TEMPLATES/index.html`).

### Method 2: Local HTTP Server
Run any local server from the `TEMPLATES` root directory:
```bash
# Using Python
python -m http.server 5000

# Or using npx
npx serve .
```
Then visit **[http://localhost:5000](http://localhost:5000)**.

## ✨ Features of the Unified Hub
* **Instant Search & Real-Time Filtering**: Search templates by name, folder, tech stack, or keyword.
* **Category Tabs**: Switch between All Templates (6), College Templates (4), and School Templates (2).
* **Direct Launch**: Open any template in a separate tab.
* **Interactive Live Preview**: Preview templates directly inside a responsive modal with Desktop (100%), Tablet (768px), and Mobile (390px) device viewport toggles.
